# Check my Chat ID

This simple Telegram bot allows you to find your `chat_id` by sending the `/start` command.
## How to Use

1. Create a new bot through [BotFather](https://core.telegram.org/bots#botfather) and get the token.
2. Insert the token into the code in the appropriate place.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Add your token to main.py
```bash
TOKEN = 'Your token'
```
5. Run
```bash
python main.py
```
6. Send the /start command to your bot, and it will reply with your chat_id.
